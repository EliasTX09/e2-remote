Danach am Gerät: MENU → DATA UTILITY → SOFTWARE UPDATE. Erst dann steht es im Flash. Geht beim Update etwas schief, sagt das Gerät „Error / Invalid File“ und schreibt nichts.

4 · Welche Datei das Update nimmt

Normalerweise öffnet SOFTWARE UPDATE immer System/SYSTEM.VSB. Mit dem Patch updatename.py steht der Name im Arbeitsspeicher und lässt sich hier setzen — dann darf die Datei heißen, wie du willst.

—

Der Name gilt bis zum Neustart. Ablauf: Datei per Kartenleser in KORG/koalatribe/System/ legen, hier den Namen setzen, dann am Gerät MENU → DATA UTILITY → SOFTWARE UPDATE.

Rettung für die erste Fassung

Die erste Fassung dieses Patches legte den Namen auf 0xC01AE000. Diese Stelle wird beim Einschalten überschrieben, der Name war also weg und SOFTWARE UPDATE meldete keine Datei gefunden. Wenn prüfen oben kaputt sagt: hier die drei Zeiger auf Korgs eigene Zeichenkette zurücksetzen, dann nimmt das Update wieder System/SYSTEM.VSB — damit kommt die neue Firmware drauf.
